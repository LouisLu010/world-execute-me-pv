# 4K60 交付说明

## 文件

- `out/same_process_4k60.mp4`
- 3840 × 2160，60/1 fps。
- H.264 / yuv420p，BT.709。
- 12,714 帧，视频时间线 211.900 秒。
- AAC 44100 Hz 原音轨直接复制，保留上传片中的结尾提示音。

## 原生重绘

工程使用 1920×1080 的逻辑坐标来描述构图。4K 导出时，逻辑坐标转换成 2 倍像素坐标：

- 字体按 2 倍字号重新栅格化；
- 线框、轨道、粒子和窗口边缘直接绘制到 3840×2160；
- Codex 终端的裁切、滚动、输入栏与字体也在 4K 上合成；
- 下方歌词轨使用相同的 395 个单词时间点；
- 保持原生 60 fps，没有插帧；
- 音频包与原 1080p 成片使用同一份提取音轨。

## 重建

```bash
python export_4k.py --workers 1
```

同一版脚本的渲染被中断后：

```bash
python export_4k.py --workers 1 --resume
```

续渲会完整解码现有分段并检查帧数、帧率和时间戳。重新编辑了画面内容后，应使用新的输出目录或进行完整渲染。

4K 默认单 worker，x264 使用低缓存编码设置；在约 2 GiB 内存的环境中可以避免多个 UHD 编码器同时占满内存。续渲也会检查旧分段的 B 帧配置，防止不同重排方式的码流在拼接处出现时间戳问题。
